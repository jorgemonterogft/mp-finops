Cambios aplicados sobre Chart.js 4.4.7

← Volver al Showcase
Contexto: Este showcase aplica el Mapfre Design System (b2b) sobre la librería Chart.js 4.4.7. Los tokens de color proceden de Default.tokens 5.json (export Figma) y se exponen como CSS custom properties desde variables.scss → charts.css. Ningún color funcional de estado (rojo de error, verde de éxito, naranja de alerta) aparece en la paleta de gráficos; los colores reservados para documentación interna (violeta) tampoco se usan.

Fecha de implementación: Marzo 2026

2. Paleta de 10 colores — criterios WCAG

Todos los colores cumplen WCAG 2.1 SC 1.4.11 (Non-text Contrast), mínimo 3:1 sobre fondo blanco #FFFFFF. Los tonos originalmente propuestos (-04 o más claros) fueron rechazados por no superar ese umbral. El rojo de marca, el naranja de alerta y el violeta de documentación quedan excluidos.

4. Arquitectura de tokens de color

Nivel Archivo Ejemplo Descripción
Nivel 1 — Primitivos variables.scss $support-blue-05: #349EA0 Valor bruto de color; 11 escalas (grey, red, pink, orange, yellow, green, green-alt, blue, blue-alt, violet)
Nivel 2 — Aliases b2b variables.scss $b2b-support-blue-05: $support-blue-05 Re-export semántico construido a partir de Default.tokens 5.json. Agrupa: rojo, gris, blanco, estados, support, transparencias, documentación.
Nivel 3 — CSS custom props charts.css --color-chart-1: #349EA0 Expuesto en :root. Leído en JS con getComputedStyle() en el objeto ALIAS.
Los colores no se codifican en duro en el JS. Todo fluye desde CSS custom properties, lo que permite cambiar el tema con solo sobrescribir las variables en :root o en un selector de clase.

5. Colores excluidos y motivo

Color / escala Hex representativo Motivo de exclusión
Rojo de marca ($b2b-red-brand) #DA2A2A Reservado exclusivamente para botones primarios y CTAs. Usar en gráficos crearía confusión semántica con acciones.
Naranja ($orange-*) #E46B15 Escala reservada para estados de alerta / warning en el DS. No existe escala naranja de uso general.
Violeta ($b2b-documentation-*) #8747FF Reservado para documentación interna. No se usa en productos finales ni en gráficos.
Support colors -01 a -04 Tonos muy claros (ej. #C1E8E9) Contraste inferior a 3:1 sobre blanco. No superan WCAG 2.1 SC 1.4.11 para objetos gráficos.
Colores de estado ($b2b-state-*) success, info, alert, error Reservados para feedback de sistema (mensajes de éxito, error, aviso). Reutilizarlos en gráficos rompe la semántica de estado.
